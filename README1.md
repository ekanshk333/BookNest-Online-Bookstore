# BookNest – Online Bookstore

## LA-II Mini Project

BookNest is a responsive online bookstore website where users can explore books, browse categories, and discover their next favorite read.

## Objectives
- Create an attractive bookstore website.
- Display books with names, authors, and prices.
- Organize books into different categories.
- Design a responsive user interface.

## Features
- Navigation bar
- Book search
- Book categories
- Bestsellers section
- Add to Cart button
- Newsletter subscription
- About section
- Responsive design

## Technologies Used
- HTML5
- CSS3
- Bootstrap 5
- JavaScript
